# Control_normal
Maya Plugin for controlling normal
Custom Maya plugin that allows users to manipulate normal nodes efficiently. The plugin provides an intuitive interface for controlling surface normals, adjusting their orientation dynamically in response to transformations. The visualization showcases a grid with normal vectors being influenced by an interactive control sphere. The plugin is useful for refining shading effects, normal mapping, and procedural modeling workflows within Autodesk Maya.
